# Save my Eyes

A Windows app that reminds you to follow the 20-20-20 rule: every every 20 minutes, look at something about 20 feet (6 m) away for 20 seconds.

Made for Windows 11. Built with WinUI 3 for a consistent look with the OS' design language.

## Features

- Highly customizable!
  - Work and break time is configurable (Default: 20 minutes and 20 seconds respectively)
  - A sound plays when a break starts and ends. Use the default sound or pick your own file (wav, mp3, wma, m4a, aac, flac)
  - Themes: Light, dark or Windows default. You can also customize every color (accent color, background, panel, text color) manually in the settings
- The window comes to the front when a break starts, and stays on top for the length of the break. If it was minimized before the break, it minimizes again when the break finishes
- Minimizing hides the app in the system tray instead of the taskbar
- The remaining time is shown in the window title and in the tray icon's tooltip
- Counter of breaks taken today


## Download
1. Download the latest .zip from [Releases](https://github.com/nic0128/save-my-eyes/releases/)
2. Extract
3. Run save-my-eyes.exe

Windows SmartScreen may show a warning since the application is unsigned. Click More Info → Run anyway to launch it.
